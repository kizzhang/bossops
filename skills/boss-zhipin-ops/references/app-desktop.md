# 桌面客户端（app 端）操作细则

先读 SKILL.md 的第三、四、五节，这里只写客户端特有的做法。

## 前提

- 会话里要有 computer use 工具。中途在 Claude 设置里打开权限，当前会话通常拿不到，要**新开会话**。
- BOSS 客户端由用户本人扫码登录好，停在「沟通」列表页。AI 不代登录。
- 提醒用户把屏幕上不想被看到的窗口收起来——读屏是截整个屏幕。

## 开工检查

1. 截一张屏，确认：客户端已登录、停在沟通列表、没有安全验证页、没有弹窗挡着。
2. **校准坐标映射**：截图里的坐标和实际点击坐标可能因为 DPI 缩放不一致。先点一个无害的位置（比如列表里已读过的一条）看落点对不对，再开始正式操作。
3. 确认今天账号状态（SKILL.md 第二节）。今天弹过验证就只读（M1）。

## 读屏

- 只用**被动的全屏截图**读内容。
- 不要对 BOSS 窗口用 PrintWindow 这类会向窗口发送消息的截图方式——它会和客户端产生交互；被动截屏对客户端没有任何影响，等同于人看屏幕。
- 关键文字（姓名、学校、日期、金额）截图后放大局部复核，不要凭缩略图认字。

## 定位候选人

- 用搜索（放大镜）→ 输入姓名 → **在结果里按面板信息选**，不要默认点第一条。
- 搜索结果有同名时，逐个看学校/年龄/当前公司/期望，选唯一匹配的。
- 点开后在右侧面板再核一遍身份（SKILL.md 第五节），通过了才往下走。
- 打开会话后**先看最近几条消息**：我方已回复或已发邀约的，跳过并记录原因。

## 输入与发送

- 文案通过剪贴板整段粘贴（如 PowerShell `Set-Clipboard`）。单段、无换行。
- 保持粘贴，**不要为了「像人」改成逐字敲**——这属于改输入特征躲检测，不做。
- 粘贴后截图核对输入框里的完整文字，确认无误再点「发送」。
- 发送后截图回执，存 `receipts/<批次名>/NN_<候选人>.png`，日志里记北京时间和状态。

## 约面试表单

按 SKILL.md 第六节的字段顺序填。日期和开始时间是下拉/日历控件：
- 小时、分钟是两列滚动列表，滚动后截图确认目标值可见再点。
- 填完**截一张整表**核对：职位、平台、会议号、备注、日期、时间、联系人，全部正确再点「发送」。
- 发出后会弹「面试邀请已发出」，会话里出现「发送了面试邀请」卡片，底部按钮变为「查看面试」，三者都在才算成功。

## 让出屏幕

- computer use 会接管鼠标和屏幕。用户有面试、会议、或要自己用电脑时，至少提前 15 分钟停手，明确告诉用户「屏幕交还给你」，并写明停在哪一步。
- 用户自己也在客户端里操作时，每条发前都要重新看一遍会话（SKILL.md 第五节「先查我方是否已经回过」）。
